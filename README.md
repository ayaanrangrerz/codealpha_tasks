# CodeAlpha Tasks

This repository contains C++ projects completed as part of the CodeAlpha Internship Program.

## Projects

### 1. Banking System
A console-based banking application that allows users to create accounts, deposit money, withdraw money, and check account balances.

### 2. Registration System
A simple user registration and login system that stores and validates user information.

### 3. CGPA Calculator
A program that calculates CGPA based on subject grades and credits entered by the user.

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling
- VS Code
